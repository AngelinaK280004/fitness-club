# Информационная архитектура и навигация

## 1. Функциональные блоки
Система разделена на 6 логических блоков:
1. **Главный экран** (точка входа).
2. **Расписание** (просмотр, детали, запись/отмена).
3. **Мои тренировки** (история, отмены).
4. **Тренеры** (список, детали).
5. **Личный кабинет** (профиль, статистика).
6. **Уведомления** и **О приложении**.

## 2. Граф состояний
На основе пользовательских сценариев разработан граф переходов между экранами. 

```mermaid
stateDiagram-v2
    [*] --> Главный_экран
    
    Главный_экран --> Расписание
    Главный_экран --> Тренеры
    Главный_экран --> Личный_кабинет
    Главный_экран --> Уведомления
    Главный_экран --> О_приложении

    Расписание --> Детали_тренировки : Выбор тренировки
    Детали_тренировки --> Звонок_оператору : Запись
