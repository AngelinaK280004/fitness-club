# Прототипы экранов (Wireframes)

В рамках низкоуровневого проектирования разработано 8 экранных форм.

1. **Главный экран:** Основная информация, кнопка вызова бокового меню.
2. **Меню:** Навигация по 6 разделам (Расписание, Мои тренировки, Тренеры, ЛК, Уведомления, О приложении).
3. **Расписание:** Календарь на месяц, список тренировок с краткой информацией.
4. **Мои тренировки:** Список записей пользователя с возможностью отмены.
5. **Тренеры:** Список с фотографиями и краткой информацией.
6. **Личный кабинет:** Личные данные, таблица со статистикой (Посещено / Пропущено / Осталось).
7. **Уведомления:** Список системных сообщений с датой.
8. **О приложении:** Логотип, версия, ссылки на соцсети, контакты.
