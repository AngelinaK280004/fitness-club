# Количественная оценка UX (GOMS-модель)

Для объективного обоснования удобства интерфейса применена модель GOMS (Goals, Operators, Methods, Selection rules) с расчетом времени выполнения действий.

**Формула:** `T = B + П × n + M × n`
- **B** (0.4 с) — время перемещения руки к устройству ввода (мышь/тач).
- **П** (1.1 с) — время указания на элемент (поиск и наведение).
- **M** (0.1 с) — время нажатия кнопки.
- **n** — количество шагов (указаний/кликов).

## 1. Запись на тренировку
*Шаги: Меню (1) → Мои тренировки (2) → Конкретный день (3) → Тренировка (4) → Кнопка «Записаться» (5).*
- **Расчёт:** `0.4 + 1.1 × 5 + 0.1 × 5 = 6.4 с`
- **Итог:** 6.4 секунды.

## 2. Отмена тренировки
*Шаги: Меню (1) → Мои тренировки (2) → Тренировка (3) → Кнопка «Отменить» (4).*
- **Расчёт:** `0.4 + 1.1 × 4 + 0.1 × 4 = 5.2 с`
- **Итог:** 5.2 секунды.

## 3. Просмотр личного кабинета
*Шаги: Меню (1) → Личный кабинет (2).*
- **Расчёт:** `0.4 + 1.1 × 2 + 0.1 × 2 = 2.8 с`
- **Итог:** 2.8 секунды.

## Вывод
Все ключевые действия занимают менее 7 секунд, что является отличным показателем для пользователей с низким уровнем владения ПК. Количественная оценка позволила обосновать выбор горизонтального меню и минимизацию шагов.
