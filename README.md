# Fitness Club 

> **Статус:** учебный кейс 
> Кейс демонстрирует полный цикл аналитика: от профилирования пользователей и формализации требований до построения информационной архитектуры, количественной оценки UX и проектирования справочной системы.

##  О проекте
Проектирование пользовательского интерфейса информационной системы фитнес-клуба. Приложение предназначено для просмотра расписания, записи и отмены занятий, просмотра информации о тренерах, работы с личным кабинетом, уведомлениями и справочной системой.

##  Проблема и цель
Клиенты фитнес-клуба вынуждены звонить оператору, чтобы узнать базовую информацию (свободные места, стоимость, расписание). Операторы тратят время на консультирование, вместо того чтобы заниматься продажами и организацией.
**Цель:** спроектировать интерфейс и формализовать требования так, чтобы клиент мог самостоятельно найти нужную тренировку, а сложные вопросы решались через понятную справочную систему и вызов оператора.

##  Моя роль и навыки

В рамках проекта я выступал в роли **системного аналитика**:

| Навык | Что выполнено | Подтверждаемый результат |
|---|---|---|
| **Анализ пользователей** | Сформированы профили пользователей (социум, мотивация, навыки работы с ПО, задачи). | Обоснованы функции интерфейса под разные группы пользователей. |
| **Формирование требований** | Определены функции приложения и границы системы. | Сформирован перечень функциональных блоков (FR). |
| **Разработка сценариев** | Описаны сценарии записи, отмены, взаимодействия с оператором. | Сценарии использованы для проверки навигации (Use Cases). |
| **Информационная архитектура** | Построена схема навигации, определены переходы между экранами. | Создан граф состояний приложения (Mermaid). |
| **Моделирование действий** | Составлены таблицы «действие — объект — примечание». | Формализована логика взаимодействия пользователя с объектами. |
| **Прототипирование UI** | Разработаны прототипы 8 экранных форм. | Создан набор экранов для основных пользовательских задач. |
| **Количественная оценка UX** | Рассчитано время выполнения действий по модели `B + П×n + M×n` (GOMS). | Запись — 6.4 с, отмена — 5.2 с, просмотр ЛК — 2.8 с. |
| **Проектирование справки** | Разработаны глоссарий, обзорная и процедурная справка, карта справки. | Создана структура справочной системы для пользователей. |
| **Документирование** | Подготовлены схемы переходов, таблицы состояний, алгоритмы. | Сформирован комплект проектной документации для передачи в разработку. |

##  Ключевые результаты
- Спроектирована структура приложения с шестью ключевыми разделами.
- Определены пользовательские роли, задачи и требования к интерфейсу.
- Построен граф состояний и обоснована навигация.
- Разработаны прототипы основных экранных форм.
- Выполнена количественная оценка времени выполнения ключевых действий (все действия ≤ 7 секунд).
- Создана справочная система (глоссарий, справка, алгоритмы).
- Реконструирована модель данных (ERD) на основе сценариев.
